نبذة عن المشروع (About The Project)
​ISALMS هو نظام إلكتروني متكامل يهدف إلى أتمتة العملية المعقدة لجدولة المحاضرات الأكاديمية داخل المؤسسات التعليمية. يقدم النظام حلاً ذكياً يقضي التام على مشكلات تضارب المواعيد والحجز المزدوج للقاعات الأكاديمية، مع الموازنة بين أوقات تفرغ أعضاء هيئة التدريس وسعة القاعات الدراسية.
​This project is an intelligent web application designed to automate academic lecture scheduling and management. It eliminates schedule conflicts, double-booking of halls, and optimizes resource allocation using modern web technologies and smart constraint algorithms.
​✨ المميزات الرئيسية (Key Features)
​الأتمتة والجدولة الذكية (Smart Scheduling): اعتماد خوارزميات الذكاء الاصطناعي وحل القيود (Constraint Satisfaction & Genetic Algorithms) لمنع تضارب المحاضرات والقاعات تلقائياً.
​إدارة الأدوار (Role-Based Access Control):
​المشرف (Admin): إدارة الأساتذة، الجداول، فحص التعارضات اللحظية، والاطلاع على الإحصائيات.
​الأستاذ (Teacher): عرض الجدول المخصص، استعادة وتحديث إعدادات الحساب والأمان.
​الطالب (Student): تسجيل حساب جديد، الاطلاع على جدول الدفعة والتخصص، وتحديث الملف الشخصي.
​السرعة والاستجابة اللحظية (Real-Time Updates): واجهات تفاعلية وسريعة تم بناؤها باستخدام React.js.
​تصدير التقارير (PDF Export): إكانية استخراج وتصدير الجداول الدراسية بضغطة زر بصيغة PDF.
​دعم ثنائي اللغة (Bilingual Support): واجهة مستخدم تدعم اللغتين العربية والإنجليزية.
​🛠️ التقنيات المستخدمة (Tech Stack)
​الواجهة الأمامية (Frontend): React.js, HTML5, CSS3, JavaScript (ES6+), Tailwind CSS / Bootstrap.
​الخلفية والخدمات (Backend): Node.js, Express.js.
​قاعدة البيانات (Database): MySQL (InnoDB engine, utf8mb4 encoding).
​تنسيق وتبادل البيانات: JSON / RESTful APIs.
​أدوات التوثيق (Documentation): PlantUML & Mermaid Diagrams (UML / DFD).
​📐 معمارية المخططات وقواعد البيانات (Architecture & Diagrams)
​يشتمل المشروع على توثيق كامل للأنظمة المخططة:
​مخطط حالة الاستخدام (Use Case Diagrams): لتوضيح أدوار المشرف والأستاذ والطالب.
​المخططات التسلسلية (Sequence Diagrams): لتتبع تدفق البيانات بين الواجهة والسيرفر وقاعدة البيانات.
​مخطط تدفق البيانات (DFD): بأسلوب منظم يوضح الآليات البرمجية المعتمدة.
